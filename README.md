# Códigos USSD Cuba v4.1

App **offline** inspirada y ampliada respecto a **UtilEs** y **QvaCall**: más códigos USSD, más accesos rápidos y sin depender de internet.

## Novedades v4.1
- **Accesos en barra de notificaciones**: 3–4 códigos configurables (Ajustes → Barra de notificaciones)
- **Módulo WiFi ETECSA** (pestaña Más → WiFi ETECSA): portal login, nauta.cu, ajustes Wi‑Fi, estado SSID
- **Tiempo restante flotante**: contador de sesión arrastrable sobre otras apps
- **Monitor de velocidad en tiempo real**: ↓/↑ con unidad, intervalo, opacidad, tamaño, posición

## Cómo usar overlays
1. Ajustes ⚙ → **Permitir ventanas flotantes** (concede permiso del sistema)
2. Activa **Tiempo restante flotante** y/o **Monitor de velocidad**
3. En Más → WiFi ETECSA puedes iniciar el contador al conectar
4. Arrastra los cuadros flotantes para moverlos
