# Códigos USSD Cuba v4.0

App **offline** inspirada y ampliada respecto a **UtilEs** y **QvaCall**: más códigos USSD, más accesos rápidos y sin depender de internet.

## vs UtilEs / QvaCall
| Función | UtilEs | QvaCall | **USSD Cuba v4** |
|---------|--------|---------|------------------|
| Consultas saldo/datos/bono/voz/SMS | ✓ | ✓ | ✓ + límite 360 CUP |
| Transferencia con PIN guardado | ✓ | ✓ | ✓ + plantillas + contactos |
| *99 y llamada anónima | ✓ | ✓ | ✓ |
| Desvíos (total / ocupado / no contesta) | parcial | — | ✓ completo |
| Transfermóvil USSD | parcial | parcial | ✓ 20+ códigos |
| Planes *133 menús directos | ✓ | ✓ | ✓ *133*1# … *133*5# |
| Widget + atajos launcher | ✓ | ✓ | ✓ |
| Temas / paletas | — | — | ✓ 6 paletas |
| 100 % offline | no siempre | no siempre | ✓ |

## Códigos incluidos (~90)
- **Consultas**: *222#, *222*328#, *266#, *869#, *767#, *732#, *264#, *468#, *111#, estados *#21# *#43# *#31#
- **Planes**: *133# y accesos *133*1…5#, *234#, transferencia directa, Adelanta
- **Recargas**: *666, *662*código#
- **Llamadas**: *99, anónima, desvíos, espera, restricción, buzón
- **Internacional**: *331 / #331
- **Transfermóvil**: login bancos, pagos, recargas, registrar tarjetas
- **Atención / Emergencias / IMEI**

## Mecánicas
- Panel de accesos rápidos (saldo, datos, bono, transferir, recargar, *99)
- Favoritos, recientes, más usados
- Diálogo de parámetros (PIN, contactos, plantillas)
- Búsqueda con sinónimos (megas, bono, 99, nauta, luz…)
- Temas oscuro/claro + 6 paletas
- Export/import favoritos JSON
- Checklist post-recarga
